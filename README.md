A sign-language application created for the **Design Championship 2026** under the **Middle Age** theme.

> [!IMPORTANT]
> This project is for demonstration purposes. Please do not copy, modify, or redistribute it without permission.

## Getting Started

### Prerequisites

Before starting, make sure you have installed:

- [Python](https://www.python.org/downloads/)
- [Git](https://git-scm.com/downloads/)

## Installation

### 1. Clone the repository

Open a terminal for your operating system and run:

```bash
git clone https://github.com/hudhvinboss-create/sign-language-app.git sign-language-app
```

### 2. Navigate to the project folder

```bash
cd sign-language-app
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

#### Windows PowerShell

```powershell
.\.venv\Scripts\Activate.ps1
```

#### macOS/Linux

```bash
source .venv/bin/activate
```

> [!NOTE]
> If PowerShell prevents the virtual environment from activating, run the following command:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Then activate the virtual environment again:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install the required packages

```bash
pip install -r requirements.txt
```

## Running the Application

### Windows

```powershell
py main.py
```

### macOS/Linux

```bash
python main.py
```
