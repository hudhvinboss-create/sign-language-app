# Sign Language Learning Guide

This project is an educational prototype. It provides dictionary metadata, visual reference cards, text-to-sign demonstrations, and translation experiments.

## Important
Sign languages are complete natural languages, not word-for-word encodings of spoken English. Word order, facial expression, movement, and regional variation matter.

## Suggested learning path
1. Learn the manual alphabet.
2. Practice numbers and common greetings.
3. Learn individual vocabulary with context.
4. Practice short phrases.
5. Study movement and non-manual signals with a qualified source.

## Asset types
- `signs/`: dictionary reference cards for the database vocabulary.
- `alphabet/`: A-Z fingerspelling study cards.
- `numbers/`: 0-9 study cards.
- `phrases/`: common phrase reference cards.
- `info/`: educational documentation.

These PNG cards are educational UI assets, not a machine-learning dataset.
