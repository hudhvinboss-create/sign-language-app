# About the Sign Language Translator

This is a prototype sign-language education and translation application. It combines a Tkinter interface, a local SQLite dictionary, computer-vision components, text-to-sign visual cards, and optional speech support.

## What it can demonstrate
- Text → Sign reference cards
- Sign dictionary browsing
- Live/video translation experiments
- Translation history
- Educational resources

## Languages
The interface supports ASL, ISL, and BSL selection. The current bundled dictionary data should be treated as prototype/educational content and verified before real-world communication use.
