# Assets

This folder contains project artwork and sign-reference documentation.

## Included
- `icons/app_icon.svg` - lightweight app icon.
- `signs/` - one SVG reference card for each sign in `database/signs.db` (114 cards).
- `signs/index.json` - machine-readable mapping between database signs and cards.
- `MANIFEST.md` - asset inventory.

> **Important:** the sign SVGs are reference cards generated from the database text. They are **not** accurate hand-sign photographs and must not be treated as machine-learning training data.
